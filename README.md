# GTA Spoiler Guard

Android-приложение (Pixel, Android 12+), которое закрывает непрозрачными плашками
упоминания GTA 6 в любых приложениях: Telegram, YouTube, Reddit, X, Chrome, уведомления.

## Как работает

- `SpoilerGuardService` — AccessibilityService. На события «контент изменился / прокрутили»
  (не чаще раза в 60 мс) обходит дерево элементов всех окон и ищет фразы в тексте
  и `contentDescription`.
- В режиме «карточка целиком» поднимается от совпавшего текста к родителю размером
  с пост или превью видео — так закрывается и картинка рядом с заголовком.
- `OverlayView` — полноэкранный `TYPE_ACCESSIBILITY_OVERLAY` с `FLAG_NOT_TOUCHABLE`:
  рисует плашки, касания проходят насквозь.
- `ToggleTileService` — плитка в шторке, чтобы быстро выключать защиту.
- Нет разрешения `INTERNET`, нет зависимостей кроме Kotlin stdlib.

## v0.6 — строки и альбомы
- Закрывается строка ближайшего прокручиваемого списка (пост, сообщение, карточка видео),
  а не «родитель до 45% экрана». Полноэкранные посты/Reels закрываются целиком.
- Соседние строки в той же полосе по высоте добавляются к области — альбомы Telegram
  (каждое фото отдельной строкой, подпись у первой) закрываются целиком.
- События окон помечают на полный обход только изменившееся окно
  (сдвиг/размер или смена экрана), а не все окна сразу.
- Пачки подгружают ещё и соседние элементы.
- Причины полных обходов в статистике.

## v0.5 — читаем только новое
- Во время полного обхода запоминаются строки каждого прокручиваемого списка.
  При прокрутке и при изменении списка читаются только строки, которых не было.
- ScrollView/WebView — обход поддерева не чаще раза в 150 мс.
- Полный обход один раз через 400 мс после остановки прокрутки и не чаще раза
  в секунду, если список целиком сообщает об изменениях.
- Статистика: число запросов к приложениям, доля ответов из кеша, время ответа.

## v0.4 — ещё быстрее
- Частичный скан: на «контент изменился» обходится только изменившееся поддерево.
- Слежение при прокрутке: найденные элементы обновляются через `refresh()`,
  блюр двигается за ними сразу; полный скан окна при прокрутке — не чаще раза в 150 мс.
- Меньше задержек: события копятся 20 мс, сканы не чаще раза в 40 мс.

## v0.3 — скорость
- Пакетная подгрузка дерева (Android 13+, `FLAG_PREFETCH_DESCENDANTS_DEPTH_FIRST`):
  один межпроцессный запрос отдаёт до 50 элементов вместо одного.
- Элементы за пределами экрана пропускаются вместе с поддеревом.
- Кеш по окнам: пересканируются только окна, в которых было событие.
- Статистика сканов на экране настроек (время, окна, элементы).

## v0.2
- **Блюр** вместо плашек: отдельное окно-диалог на каждую область с
  `Window.setBackgroundBlurRadius`. Если система отключила размытие
  (энергосбережение), автоматически рисуются плашки.
- **Слова-спойлеры**: второй список (концовка, умер*, ending, dies…) закрывается,
  только если на экране есть GTA или в этом приложении GTA была за последние 3 минуты.
  `*` в конце слова = любое окончание.
- **Параноидальный режим**: пока большая лента прокручивается, она закрыта целиком.
- Постоянный ключ подписи `app/personal.keystore` — обновления ставятся поверх.
- CI прикрепляет APK к GitHub Release (удобно качать с телефона).

## Сборка

### Вариант А: Android Studio (Mac)
1. Открыть папку проекта в Android Studio, дождаться Gradle sync
   (если предложит обновить AGP — можно соглашаться).
2. На Pixel: Настройки → О телефоне → 7 раз тапнуть «Номер сборки»,
   затем Для разработчиков → «Отладка по USB» (или «Отладка по Wi-Fi»).
3. Подключить телефон, нажать Run ▶.

### Вариант Б: GitHub Actions (без Android Studio)
1. Залить проект в приватный репозиторий на GitHub.
2. Actions → «Build APK» соберётся сам на push.
3. Скачать артефакт `gta-spoiler-guard-apk` прямо с телефона, распаковать zip, открыть APK.

## Включение на телефоне
1. Открыть приложение → «Включить в спецвозможностях».
2. Спецвозможности → «Скачанные приложения» → GTA Spoiler Guard → включить.
3. Если переключатель серый («Ограниченная настройка»): Настройки → Приложения →
   GTA Spoiler Guard → ⋮ → «Разрешить ограниченные настройки», повторить шаг 2.
4. По желанию: добавить плитку «Спойлеры GTA» в быстрые настройки.

## Ограничения v0.1
- Видит только текст и подписи. Кадры из видео и картинки без подписи не ловит
  (частично помогает режим «карточка целиком»).
- При очень быстрой прокрутке плашка может отстать на доли секунды.
- Плашки — непрозрачные, не блюр: надёжнее, и блюр всё равно оставляет текст читаемым.
